# Сайт майстра (міні-сайт)

Статичний одностраничний сайт: HTML + WebP-зображення, без збірки.

## Локальний перегляд

Відкрийте `index.html` у браузері або запустіть будь-який статичний сервер, наприклад:

```bash
npx serve .
```

## Деплой на Vercel

1. Імпортуйте репозиторій у Vercel (New Project → Import Git Repository).
2. Framework Preset: **Other**. Build Command і Output Directory залиште порожніми.
3. Натисніть Deploy. Налаштування з `vercel.json` застосуються автоматично.

## Структура

- `index.html` — уся сторінка (стилі та скрипти вбудовані).
- `assets/` — зображення у WebP.
- `vercel.json` — кешування зображень і базові заголовки.
